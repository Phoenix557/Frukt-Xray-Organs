# X-Ray

Shows bones and organs in [FRUKT](https://store.steampowered.com/app/2740330/FRUKT/) by [Phoenix557](https://github.com/Phoenix557). Bones and organs can be on at the same time. Two buttons sit above the game toolbar, and the keys can be changed in the pause menu.

## Prerequisites

Install these before `XRay.dll`. X-Ray does not start correctly without them.

1. **FRUKT**, the Steam game by tripledose.
2. **[MelonLoader](https://melonwiki.xyz/#/)** installed on that game. In the installer, pick `FRUKT.exe`.
3. **Phx** (`Phx.dll`) in the same `Mods` folder. X-Ray registers its keys with Phx. Without `Phx.dll`, the mod has no settings page and will not load its hotkeys. Pause the game and open **PHX PAUSE** to change them.

Walking is not required.

## Install

1. Close FRUKT. The game locks files in `Mods` while it is running.
2. Put `Phx.dll` in `Mods` if it is not already there.
3. Put `XRay.dll` in that same folder.

Steam's default folder is:

```
C:\Program Files (x86)\Steam\steamapps\common\FRUKT\Mods
```

4. Start FRUKT.

Default keys are **X** for bones and **O** for organs. Change them under **PHX PAUSE**. The same switches are the two buttons above the toolbar.

## Update

Close FRUKT, replace `XRay.dll` in `Mods`, and start the game again.

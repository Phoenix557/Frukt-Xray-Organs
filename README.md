# X-Ray

Shows bones and organs in FRUKT by Phoenix557.
https://github.com/Phoenix557/Frukt-Xray-Organs/releases

## Prerequisites

Install these before `XRay.dll`. X-Ray will not load without them.

1. **MelonLoader**. Pick `FRUKT.exe` in the installer.
https://melonwiki.xyz/#/
2. **PhxCore** (`PhxCore.dll`) in the `Mods` folder. Keys are under **PHX MODS**.
https://github.com/Phoenix557/Frukt-PhxCore

## How it plays

Bones and organs can be on at the same time. Two buttons sit above the game toolbar.

**X** shows bones. PHX MODS > X-RAY > BONES
**O** shows organs. PHX MODS > X-RAY > ORGANS

## Install

1. Close FRUKT.
2. Put `XRay.dll` in `C:\Program Files (x86)\Steam\steamapps\common\FRUKT\Mods`
3. Start FRUKT.
